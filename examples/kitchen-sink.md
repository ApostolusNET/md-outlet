# md-outlet 記法カタログ（kitchen sink）

このファイルは、md-outlet で使える Markdown の書き方を一覧したものです。  
UI ヘッダーの **ガイド → 記法カタログ** から開けます。

```bash
npx md-outlet ui
```

## コード

インラインは `const x = 1` のように書きます。

フェンス付き（言語指定あり）:

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

言語なし:

```
plain text block
line 2
```

## md-outlet 独自（紙面用）

### 手書き改ページ

次のブロックの直後でページが切れます。

<div class="page-break"></div>

### 改ページ後の見出し

ここは改ページのあとに来ます。

### まとめて切らない（keep-together）

<div class="keep-together">

#### この塊はできるだけ同じページに

| 項目 | 値 |
|------|----|
| A | 1 |
| B | 2 |
| C | 3 |

途中で表だけ次ページに飛ぶのを避けたいときに使います。

</div>

エディターでは **改ページ** / **まとめて表示** ボタンでも挿入できます。
